# Minos 로컬 에이전트 시스템 매뉴얼 (Minos Local Agent System Manual)

## 1. 시스템 개요 (System Overview)
Minos는 Ollama(로컬 LLM)를 두뇌로 사용하는 완전히 독립적인 자율 에이전트 시스템입니다. 기존의 단방향 챗봇(OpenClo, Hermes)을 뛰어넘어, **자율 신경계(Tentacles)**와 **행동 스킬(Skills)**, 그리고 **장기/단기 기억 장부(Memory Engine)**를 결합하여 사용자(형님)의 윈도우 환경을 제어하고 정보를 실시간으로 모니터링합니다.
이 시스템은 **PC의 SSD 환경에서 상시 구동되는 것을 기본(Default)으로 설계**되었으며, 인터넷 연결이나 외부 클라우드 의존 없이 100% 로컬 성능을 발휘합니다. 또한 모든 데이터와 환경 설정이 폴더 내에 집중되어 있어, 비상시나 PC 이동 시 **USB에 담아 즉시 백업 및 구동(Portable)**할 수 있는 유연성을 제공합니다.

### ⚠️ 타 PC 구동 필수 조건 (Portable Requirements)
만약 이 시스템(USB)을 **새로운 컴퓨터에서 즉시 구동**하려면, 새 컴퓨터에 다음 3가지 조건이 갖춰져 있어야 합니다.
1. **Python 3 설치:** 에이전트의 신경망(파이썬 스크립트)과 대시보드 웹 서버를 구동하기 위한 필수 엔진입니다.
2. **Ollama 구동 상태:** Minos의 실제 '두뇌(LLM)' 역할을 하는 Ollama가 백그라운드에 실행 중이어야 합니다.
3. **AI 모델 다운로드:** Ollama 엔진 내부에 Minos가 사용하는 텍스트 분석 모델(예: llama3, gemma 등)과 기억 처리용 임베딩 모델(`nomic-embed-text`)이 `pull` 되어 있어야 합니다.
*(위 조건들은 동봉된 `Setup-Environment.bat` 파일을 한 번 실행하여 자동으로 구축할 수 있습니다.)*

## 2. 코어 프로세스 및 동기화 (Core Process & Synchronization)
Minos 시스템은 텔레그램(모바일)과 웹 대시보드(데스크톱) 양방향으로 완벽한 **거울 모드(Mirroring Sync)**를 지원합니다.

### 데이터 흐름 (Workflow)
1. **입력:** 사용자가 텔레그램 메신저나 브라우저 대시보드를 통해 명령을 내립니다.
2. **뇌(Core Engine):** `core_engine.py`가 명령을 수신하고, 현재 자신의 상태(CPU/RAM 부하, 메모리 포화도)와 보유한 스킬들을 파악하여 스스로 어떻게 행동할지 결정합니다.
3. **기억(Memory Engine):** 결정된 행동과 결과를 `memory_logs/` 디렉토리에 있는 JSON 파일에 지속적으로 저장합니다. 단기 기억이 꽉 차면 자동으로 압축/유실 처리하여 부하를 조절합니다.
4. **동기화(Sync):** 대시보드에서 보낸 명령은 즉각 텔레그램 API를 거쳐 모바일로 알림(`Push`)을 보내고, 텔레그램에서 보낸 명령은 대시보드가 5초 단위로 메모리를 읽어(`Pull`) 화면에 실시간으로 표시합니다.

## 3. 초경량 범용 메모리 엔진 (Memory Processing Logic)
Minos 시스템의 가장 핵심적인 기능은 3계층 기억 구조와 하이브리드 RAG(검색 증강 생성)가 결합된 `Memory Engine`입니다. Minos는 한정된 컨텍스트(문맥) 길이를 극복하기 위해 인간의 기억 처리 방식을 모방하여 설계되었습니다.

### 3-Tier 메모리 아키텍처
1. **단기 기억 (Working Memory):** 최근 대화 내역을 최대 설정값(기본 30턴)까지만 유지합니다. 대화가 한계치에 도달하면 가장 오래된 기억부터 자동으로 밀어내어(FIFO) 시스템의 컨텍스트 초과 오류를 방지하고 응답 속도를 일정하게 유지합니다.
2. **장기/의미 기억 (Semantic Memory):** 사용자의 핵심 정보, 선호도, 절대 잊어선 안 되는 지식 베이스를 압축하여 시스템 프롬프트에 상시 주입합니다.
3. **일화 기억 (Episodic Memory):** 모든 대화 내역은 삭제되지 않고 `jsonl` 파일과 벡터 데이터베이스(ChromaDB)에 타임스탬프와 함께 영구 보존됩니다.

### 하이브리드 RAG (검색 증강 생성) 처리 프로세스
사용자가 새로운 질문을 입력하면, Minos는 즉시 대답하지 않고 다음 과정을 거칩니다:
1. **벡터 임베딩 검색 (옵션 B):** 사용자의 질문을 `nomic-embed-text` 모델을 통해 벡터로 변환하고, ChromaDB를 뒤져 과거의 '일화 기억' 중 가장 유사도가 높은 Top-K 개의 대화 기록을 추출합니다.
2. **키워드 폴백 검색 (옵션 A):** 만약 ChromaDB에 오류가 발생하거나 구동할 수 없는 환경일 경우, 즉시 `BM25` 알고리즘을 사용한 키워드 기반 텍스트 매칭 검색 모드로 자동 전환(Fallback)되어 안정성을 보장합니다.
3. **프롬프트 주입:** 검색된 과거의 기억들을 현재의 질문과 융합하여 `[과거 연관 대화 기록]` 이라는 이름으로 LLM의 프롬프트에 동적으로 주입합니다.
이 과정을 통해 Minos는 수만 줄의 대화를 나누더라도 속도 저하 없이 과거의 맥락을 정확히 기억하고 대답할 수 있습니다.

## 4. 스킬 시스템 운용 (Skill System Operation)
스킬은 Minos가 직접 윈도우 시스템을 제어하거나 외부 정보를 가져올 때 쓰는 "손과 발"입니다. `skill_system/skills/` 폴더에 `.py` 형태로 존재합니다.

### 주요 스킬 목록 및 기능
- **PC_System_Status.py**: 현재 PC의 CPU, RAM, 저장 공간 상태를 조회합니다.
- **process_manager.py**: 윈도우에서 실행 중인 프로세스를 강제 종료하거나 상태를 봅니다.
- **local_file_reader.py / clipboard_manager.py**: 텍스트 파일을 읽거나 클립보드를 제어합니다.
- **screen_ocr.py**: 화면에 있는 글자를 인식하여 텍스트로 변환합니다.
- **web_search.py / web_scraper.py**: 실시간 인터넷 검색 및 웹페이지 스크래핑을 수행합니다.
- **tentacle_manager.py**: 백그라운드 문어발(데몬)들을 켜고 끄거나 상태를 조회합니다.
- **gui_output_engine.py**: 결과를 별도의 GUI 창으로 깔끔하게 띄워줍니다.

### 스킬 승인 (Auto-Approve)
위험할 수 있는 명령어는 대시보드나 텔레그램에서 "사용자 승인"을 받아야 합니다. 하지만 자주 쓰는 안전한 스킬들은 대시보드 좌측의 **[Skills (Auto-Approve)]** 패널에서 스위치를 켜두면 Minos가 묻지 않고 0.1초 만에 자동 실행합니다.

## 5. 자율 신경계 운용 (Tentacle Daemon System)
Tentacle(문어발)은 Minos가 백그라운드에서 조용히 실행하며 실시간으로 정보를 감시하는 촉수입니다. `tentacles/` 폴더에 `.py` 형태로 존재하며 `tentacle_daemon.py`가 이들을 총괄합니다.

### 주요 문어발 및 기능
- **morning_brief_tentacle.py**: 아침마다 날씨나 주요 뉴스를 수집하여 브리핑을 준비합니다.
- **stock_tiger_tentacle.py**: 특정 주식 종목이나 지표를 실시간으로 모니터링하다가 급변 시 에이전트의 뇌(Core)에 신호를 줍니다. (그러면 Minos가 사용자에게 선톡을 보냅니다!)

### 운용 방법
대시보드 좌측 **[Tentacles (Daemon)]** 아코디언 메뉴에서 각 문어발의 토글 스위치를 클릭하여 실시간으로 켜고 끌 수 있습니다. 

## 6. 유지보수 및 실행 방법 (Maintenance & Execution)
### 시스템 실행
- `C:\ai\Antigravity_Memory_Engine\Start-Minos.bat` 파일을 더블클릭합니다.
- 텔레그램 봇과 대시보드 서버가 2개의 터미널 창으로 동시에 켜집니다.
- 브라우저를 열고 `http://localhost:5000`에 접속하면 관제 대시보드가 나타납니다.

### 텔레그램 봇 연동
- 대시보드 왼쪽 맨 아래 **[⚙️ Telegram Config]**를 클릭합니다.
- `@BotFather`를 통해 발급받은 텔레그램 토큰을 입력하고 Save를 누릅니다. 시스템이 알아서 `bot_config.json`에 암호화 없이 저장합니다.

### 새로운 스킬 추가
Minos 채팅창에 "이러이러한 기능을 하는 파이썬 코드를 짜서 새로운 스킬로 저장해줘" 라고 명령하면, Minos가 스스로 코드를 짜서 `skills/` 폴더에 새 `.py` 파일을 만들고 즉시 장착합니다.
